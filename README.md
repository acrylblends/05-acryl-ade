|---|---|
| macOS, Apple silicon (M1 and later) | [ACRYL-ADE-mac-arm64.dmg](https://github.com/acrylblends/05-acryl-ade/releases/latest/download/ACRYL-ADE-mac-arm64.dmg) |

| Windows (most PCs) | [ACRYL-ADE-win-x64.exe](https://github.com/acrylblends/05-acryl-ade/releases/latest/download/ACRYL-ADE-win-x64.exe) |

These links always give the newest version. Every version: [Releases](https://github.com/acrylblends/05-acryl-ade/releases).

First start: on macOS the app is not signed yet, so right-click it and choose Open. On Windows, if SmartScreen asks, click More info and then
Run anyway. On Linux, double-click the .deb file to open it in the Software app.

This repository holds only the releases. The source is in the ACRYL monorepo:
[acryldev/acryl/apps/acryl-ade](https://github.com/acryldev/acryl/tree/main/apps/acryl-ade), released there under the tags `ade-v*`. ACRYL ADE is also a Blend in
the registry: [acrylblends.github.io](https://acrylblends.github.io/blends/ai/ade/acryl.ade).
